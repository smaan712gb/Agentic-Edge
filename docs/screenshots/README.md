# Screenshots

Drop your application screenshots in this directory. The repo's main README
references the following filenames — replace them with real captures and
they'll render automatically:

- `themes.png` — the Themes page with two or three themes visible.
- `run.png` — a run in flight showing the agent workflow diagram and
  some intermediate analyst output.
- `scorecard.png` — the final scorecard for a completed run, with the
  ranked tickers and the per-ticker drill-down.
- `performance.png` — the Performance page with the equity curve and
  current positions.
- `kill-switch.png` — the kill switch component in the sidebar.

Tips:

- Use 16:9 or 16:10 aspect ratio for consistency.
- Crop tightly to the relevant content; whitespace is wasted in a README.
- Annotate sparingly. The UI should explain itself.
- Make sure no live API keys, account numbers, or P&L values you wouldn't
  want public are visible. The IBKR account ID in particular is worth
  blurring out of any frame that captures it.
